Sorta

Your folders, sorted. Automatically.

Sorta files new downloads, screenshots and documents into tidy folders the moment they arrive. Preview every move first, and undo anything.

Common questions

How do I start? Open Sorta and click Tidy My Downloads, or Add Desktop…. Click Preview… to see what would move, then Move Files. When you're happy, switch on Tidy automatically.

A file moved and I want it back. Open Activity (or the menu bar icon) and click Undo. Sorta leaves files you put back where they are. To let Sorta file them again, click Let Sorta File Them on the folder's page.

Will Sorta move a file while it's still downloading? No. Partial downloads are skipped, and any file changed in the last few seconds waits until it's finished.

Does it look inside my subfolders? No. Only files sitting directly in a folder you add are sorted. Your existing folders are never touched.

Can it overwrite a file? Never. If a file with the same name already exists, the new one gets a number, like “Report 2.pdf”.

A folder says “Can’t open”. The folder moved, its drive is unplugged, or permission was removed. Plug the drive back in (Sorta checks every minute), or click Choose Again….

How do I stop it? Toggle Pause in the menu bar, switch off Tidy automatically for one folder, or remove the folder.

Undo says it can’t reach a file in the Trash. Open the Trash in Finder, Control-click the file and choose Put Back.
